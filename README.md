# EarthOS

EarthOS is an experimental multi-service operating-system prototype maintained in the `earth-os/` directory.

**Current status:** development prototype. This repository does not currently contain the advertised Next.js `ui/` application, and the historical build report is not a current verification of functionality.

Start with [the project README](./earth-os/README.md) and [Getting Started](./earth-os/GETTING_STARTED.md) for the actual service layout and setup instructions.

The tracked Python virtual environment has been removed from version control. Recreate local environments on each developer machine; do not commit `.venv/`, compiled Python files, or installed dependencies.
